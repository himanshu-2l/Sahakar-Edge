# UI / UX Specification

## Visual principle

Government/engineering product, not flashy AI SaaS.

### Design

-   clean white/light surfaces
-   navy primary
-   green for healthy/synced/success
-   orange for edge/local processing
-   red only for errors/risks
-   high contrast
-   compact cards
-   clear status badges
-   no glassmorphism
-   no neon
-   no AI brain imagery
